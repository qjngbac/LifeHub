# LifeHub V1.9.8 Android 安装与使用

## 兼容范围

- 仅支持 Android，不提供 iOS、Windows 或网页版。
- 最低系统版本：Android 7.0（API 24）。
- 安装包架构：arm64-v8a，适用于目前绝大多数 64 位 Android 手机。

## 安装

1. 从 GitHub Releases 下载 `LifeHub-V1.9.8.apk`。
2. 将 APK 保存到 Android 手机，并在文件管理器中点击安装。
3. 如系统拦截，请进入“设置 → 安全/隐私 → 安装未知应用”，仅对当前文件管理器临时允许。
4. 安装完成后关闭“安装未知应用”权限。

若手机中安装过签名不同的测试包，Android 可能提示无法覆盖安装。这种情况下请先在旧版中导出备份，再卸载旧版并安装本版。

## 首次使用建议

- **通知**：允许后才能收到任务、习惯、课程、用药和证件提醒。
- **定位**：仅在刷新天气时使用；拒绝后仍可使用核心离线功能。
- **后台运行**：如需稳定提醒和组件刷新，建议在电池设置中允许 LifeHub 后台活动。
- **桌面组件**：长按桌面空白区域，在小组件列表中找到 LifeHub，可添加“今日概览”或“后续课程”。

不同厂商对后台应用的限制不同。若提醒延迟，可将 LifeHub 的电池策略设置为“不限制”，并按需允许自启动。

## 快速上手

- **今天**：查看任务、日程、课程、习惯、纪念日和即将出发的旅行。
- **日程**：使用日、周、月视图查看安排，也可导入或导出 ICS 文件。
- **中间 `+`**：快速创建任务、日程、项目、清单、习惯或收藏。
- **数据**：进入课程表、目标、专注、资料、旅行、生活记录和离线知识模块。
- **我的**：管理提醒、备份与恢复、数据健康和本地自动化。
- **Android 分享**：在其他应用分享文本时选择 LifeHub，内容会进入收件箱。

## 数据与升级

- 核心数据保存在手机本地，不需要服务器或账号。
- 卸载 LifeHub 或清除应用数据会删除本机数据。
- 升级、卸载或更换手机前，请在“我的”中导出密码加密备份并牢记密码。
- 完整备份包含应用管理的附件；仅数据备份不复制附件文件。

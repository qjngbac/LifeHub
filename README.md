# LifeHub

> 本地优先、离线可用的 Android 个人生活管理应用。

LifeHub 使用 Flutter 开发，把任务、日程、课程表、习惯、资料、旅行和常用生活知识放在同一个应用中。核心数据默认保存在手机本地，不需要注册账号，也不依赖服务器才能使用。

- 当前版本：**V1.9.6**
- 支持平台：**Android 7.0（API 24）及以上**
- 安装包架构：**arm64-v8a、armeabi-v7a、x86_64**

[前往 Releases 下载 Android APK](https://github.com/qjngbac/LifeHub/releases/latest)

## 主要功能

### 计划与执行

- 任务、子任务、项目、清单和习惯
- 日、周、月日程视图，以及 ICS 导入导出
- 课程表、学期周次、单双周、连堂课程和 Android 桌面组件
- 长期目标、里程碑、关联进度、专注与计时、周/月复盘
- 收件箱、晚间规划、本地自动化和统一关联中心

### 生活记录

- 心情日历、关系空间、纪念日
- 旅行计划、地点、旅行账单和附件
- 家庭物品与保修、证件到期、用药提醒与本地急救卡
- 轻量收支、快递取件、阅读进度和影视进度

### 资料与离线知识

- 支持便签、图片和文件附件的本地资料库
- 按地区整理的野外急救与求生知识
- 日用品选购知识库和常见药品信息库
- 笑话与故事支持模块内搜索、收藏、屏蔽和稍后阅读
- 全局搜索只收录适合全局查找的重要数据；娱乐内容和影视记录仅在模块内搜索

### 数据管理

- JSON 完整备份或仅数据备份
- 使用 Argon2id 与 AES-256-GCM 的密码加密备份
- 合并恢复、替换恢复、恢复前检查和数据健康检查
- 归档与最近删除分离
- 数据页模块排序、固定、隐藏和恢复默认布局

## 离线与联网边界

LifeHub 的任务、日程、课程表、资料、知识库、搜索、备份等核心功能均可离线使用。

以下功能需要网络或系统能力：

- 天气：定位由 Android 系统提供，天气与空气质量由 Open-Meteo 获取；断网时保留上次成功缓存。
- 通知和提醒：依赖 Android 通知、精确提醒、后台运行及电池策略。
- 桌面组件：由 Android 桌面启动器提供，系统可能根据省电策略延后刷新。

应用不会要求登录，也没有配套云端服务器。详细说明见 [隐私说明](PRIVACY.md)。

## 安装

1. 在 [Releases](https://github.com/qjngbac/LifeHub/releases/latest) 下载 `LifeHub-V1.9.6.apk`。
2. 在 Android 文件管理器中打开 APK。
3. 如系统拦截，请仅为当前文件管理器临时允许“安装未知应用”。
4. 首次打开后，按需要授予通知和定位权限。

升级或卸载前，建议先在“我的”中导出密码加密备份。卸载应用或清除应用数据会删除手机上的 LifeHub 本地数据。

更完整的手机设置说明见 [Android 安装与使用](docs/ANDROID_INSTALL.md)。

## 权限用途

| 权限或系统能力 | 用途 | 是否影响核心离线功能 |
| --- | --- | --- |
| 通知 | 任务、习惯、课程、用药和证件提醒 | 拒绝后仅不提醒 |
| 定位 | 获取当前位置并查询当地天气 | 拒绝后可使用已保存地区或天气缓存 |
| 网络 | 刷新天气和空气质量 | 断网时其他功能可继续使用 |
| 后台运行/开机恢复 | 恢复提醒、自动备份和桌面组件 | 受系统省电策略影响 |

## 本地开发

### 环境要求

- Flutter 3.32 或更高版本
- Dart 3.5 或更高版本
- JDK 17
- Android SDK（compileSdk 36）

### 获取依赖与生成代码

```bash
flutter pub get
dart run build_runner build --delete-conflicting-outputs
```

项目包含一份经过兼容修正的 `workmanager_android`，位于 `third_party/workmanager_android`，因此克隆仓库后不需要访问开发者电脑上的绝对路径。

### 运行与检查

```bash
flutter run
flutter analyze
flutter test
```

### 构建 Android APK

```bash
flutter build apk --release
```

发布签名配置不在仓库中。自行构建时，若没有配置发布密钥，项目会使用本地可用的调试签名；正式分发请配置自己的密钥，切勿提交 `key.properties`、`.jks` 或 `.keystore` 文件。

## 目录结构

```text
lifehub/
├─ android/                  Android 原生代码、通知与桌面组件
├─ assets/                   图标、图片和离线知识库内容
├─ integration_test/         集成测试
├─ lib/                      Flutter 应用源码
│  ├─ app/                   路由、主题与主界面
│  ├─ core/                  数据库、备份、通知等基础能力
│  ├─ features/              各业务模块
│  └─ shared/                公共组件和工具
├─ test/                     单元测试与组件测试
├─ third_party/              仓库内兼容依赖及其许可证
└─ tool/                     内容生成和稳定性检查脚本
```
